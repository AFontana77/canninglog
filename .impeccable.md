# CanningLog — Impeccable Design Context

## Design Context

### Users
Home canners, homesteaders, food preservers, jam-makers, pickle obsessives. They follow USDA processing times exactly because botulism is real. They're in the kitchen during peak harvest, jars on the counter, checking processing times for their altitude. Phone splattered. Thumbs sticky.

### Brand Personality
Three words: **precise, nostalgic, farmstead.**

This is a USDA-grade reference disguised as a kitchen journal. Old-school food preservation knowledge with rigorous safety standards. Think Ball Blue Book aesthetic, not modern foodie blog.

### Aesthetic Direction
**Light theme.** Kitchen, daytime, warm jars on a sunny windowsill.

**Font pair:**
- Display: `Yeseva One` — vintage editorial serif with hand-lettered quality. Reads like an heirloom recipe book cover or a 1940s farm journal. NOT in reflex list.
- Body: `Hind` — clean humanist sans for body. Excellent at recipe-step readability.

**Color system (OKLCH, light cream-green):**
- Background: `oklch(0.97 0.012 105)` — warm cream with green hint
- Surface: `oklch(0.94 0.018 105)` — light sage cream
- Foreground: `oklch(0.18 0.025 130)` — dark forest with green tint
- Muted foreground: `oklch(0.46 0.018 130)`
- Border: `oklch(0.84 0.018 105)`
- Primary (canning-jar green): `oklch(0.40 0.12 145)` — deep preservation green
- Primary dark: `oklch(0.32 0.10 145)`
- Accent (peach): `oklch(0.70 0.15 60)` — for highlighted items, like a peach preserve

### Design Principles
1. **USDA processing times are non-negotiable** — display with table precision and visual weight.
2. **Editorial cookbook layout** — left-aligned, asymmetric, never centered grid cards.
3. **Safety messaging gets clear visual treatment** — but not panic-red banners. Calm, authoritative.
4. **Recipes look like recipes** — not feature cards. Use bordered table rows for cook-time data.
5. **Warm cream + deep green** — feels like opening a vintage Ball jar, not a SaaS dashboard.
